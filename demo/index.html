What this is

A click-through of OpsPilot: an AI agent reads a support ticket, retrieves that company's own knowledge, drafts a cited reply — and cannot publish it. A human approves the exact text, or nothing goes out.

What's real, with evidence

  • Ticket list p95 149.93 ms → 36.91 ms, throughput 1,264 → 4,646 req/s
  • 60 fictional eval cases: 0 forbidden actions executed, 100% approval recall
  • Worker killed mid-action with SIGKILL: exactly one published reply
  • 265 Java, 355 Python, 54 web, 11 end-to-end tests

What isn't

  • Nothing is deployed — there is no live instance of the real stack
  • No real model has ever been called; the agent runs on a deterministic mock
  • This page simulates the backend entirely in your browser
